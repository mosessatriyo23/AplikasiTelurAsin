# QC P0 — 25 Oktober 2026

## Keputusan pemilik

- COD: H-1 pukul 18.00 WIB dari requestedDate, minimal 24 jam sejak dibuat (ambil yang lebih akhir).
- Checkout ambigu: bukti API Midtrans authoritative terminal expire/cancel/deny/failure yang baru + otorisasi satu admin sebelum stok dilepas. 404/timeout saja tidak cukup.

## Perubahan

- GET status hanya membaca database lokal; tidak memakai limiter gateway atau memanggil Midtrans.
- POST `/api/orders/[token]/sync` memverifikasi origin, rate limit per order, identity bila trusted, dan klaim DB cooldown 60 detik. Shared-untrusted tidak menggabungkan semua pembeli dalam satu bucket sync.
- Shared hook polling 20 detik memakai subscriber lokal/BroadcastChannel dan lease localStorage; hidden tab berhenti, Retry-After/backoff dihormati. PAID tetap polling fulfillment; completed/cancelled/refunded menghentikan jadwal. Lease antar tab bersifat best-effort, bukan lock atomik; keselamatan gateway tetap ditegakkan server.
- COD future deadline mengikuti keputusan pemilik, tanggal batas ditampilkan di detail. Tidak ada backfill deadline historis terhadap DB asli.
- Checkout NONE/CREATING/ACTIVE/AMBIGUOUS/DEFINITIVE_FAILURE/TERMINAL_CONFIRMED/RESOLVED. HTTP400 validation rejection terstruktur dibedakan dari timeout tetapi tidak otomatis restock. Klaim CREATING >2 menit dieskalasi worker. Dashboard menyediakan filter Review checkout dan resolusi admin. Status terminal review tidak otomatis melepaskan reservasi. Resolusi fresh API + transaksi/CAS mengembalikan stok tepat sekali; late settlement tetap REVIEW.
- Full refund/chargeback absorbing: respons settlement/capture terlambat tidak dapat mengubah CANCELLED+REFUNDED menjadi PAID. Refund amount tidak turun dan pemasukan full refund nol.
- Test migration menjalankan process.execPath + resolusi tsx/cli, bukan tsx.cmd. Rollback terkontrol memakai SQLite trigger: update pertama terjadi, update kedua gagal, seluruh update dan marker transaksi dibuktikan rollback.
